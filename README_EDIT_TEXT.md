# R13 页面文字编辑

所有 HTML 文案已支持页面内直接编辑。

1. 用 `OPEN_SITE.sh` 或便携包 `RUN.sh` 启动网站。
2. 页面右下角点击 `✎`。
3. 点击“编辑文字”，直接点任何网页文字修改。
4. 修改会自动保存到浏览器，也可以点击“立即保存”。
5. `Ctrl+S` / `Command+S` 也会保存。
6. “导出文案”会生成 JSON；换电脑后用“导入文案”恢复。

注意：PNG/JPG/WebP 图片本身内部的文字不是 HTML 文案，无法用浏览器直接编辑。方法流程图等图片需要替换图片文件。

顶部导航已统一为三个业务主标题：
- LTMap 长尾场景感知
- VGGT-Omega 三维重建
- LTMap × World Model

桌面端悬停或键盘聚焦主标题会显示对应子导航。

# LTMap3D Portfolio Site R4

This package is a full static website. Upload the directory contents to the web root for `gridtycoon.online`.

Primary pages:
- `/index.html`
- `/ltmap/index.html`
- `/vggt/index.html`
- `/world-model/index.html`

R4 changes are concentrated in `/ltmap`:
- MapTRv2-inspired academic project-page organization;
- exact user-selected method figure;
- LTMap-only quantitative results;
- Mask2Map BEV qualitative results;
- real dynamic-track BEV results and clean track videos;
- Canvas2D semantic point-cloud viewer with no WebGL dependency and a visible fallback image.

No server-side runtime is required.
